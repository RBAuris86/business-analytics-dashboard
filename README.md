# Business Analytics Dashboard

AURIS Technologies demo project for business reporting, KPI tracking, and operational analytics.

## Purpose

This project demonstrates how AURIS Technologies can help businesses replace spreadsheets and manual reports with a clean, interactive dashboard.

## Features

- KPI summary cards
- Revenue and performance tracking
- Task/status overview
- Demo business data
- Responsive dashboard layout

## Tech Stack

- React
- TypeScript
- Vite
- CSS
